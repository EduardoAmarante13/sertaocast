\# SertãoCast



Plataforma web desenvolvida para o SertãoCast, com frontend em React e API backend em FastAPI.



\## Tecnologias



\### Frontend

\- React

\- React Router

\- Tailwind CSS

\- Radix UI

\- Axios

\- Recharts



\### Backend

\- Python

\- FastAPI

\- MongoDB

\- Motor

\- JWT

\- Uvicorn
